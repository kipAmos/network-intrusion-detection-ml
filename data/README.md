# Dataset

Place the labelled network-flow CSV file in this folder and name it:

`network_traffic.csv`

The target column should be named `Label`, `Class`, `Attack`, or `Target`.
If it has another name, pass it with `--target YOUR_COLUMN`.

The CSV should contain numeric or categorical flow features and one target/label
column. Do not commit private, confidential, or licensed datasets to a public
repository unless you have permission to redistribute them.

A suitable research dataset is CIC-IDS2017. Download it from its official
research project source and follow its terms of use. This repository does not
include the dataset.
